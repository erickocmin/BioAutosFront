# Componentes

- `AppLayout`, sidebar, topbar y breadcrumbs.
- `DataTable`, `ResourceTable`, búsqueda y paginación server-side.
- `Modal`, `ConfirmDialog`, `FormSection`, `StatusBadge` y `PermissionGate`.
- Estados de loading, skeleton, vacío y error.

`ResourceTable` conserva en React únicamente la página actual; búsqueda, filtros y paginación pertenecen al backend.
