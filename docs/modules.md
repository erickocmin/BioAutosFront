# Módulos

Pantallas operativas: dashboard; CRUD de empresas, sucursales, usuarios, empleados y cajas; asignación de perfiles y matriz de permisos; productos/stock; compra, salida y traslado; kardex de solo lectura; arqueo, detalle, conteo y cierre; marcaciones filtrables; asistencia diaria; y estado de dispositivos con última conexión/marcación. Attendance presenta PIN desconocidos para facilitar su asociación posterior y omite `raw_data` de los listados.

Los módulos `ticketing`, `fleet`, `cargo` y `billing` permanecen bloqueados y no tienen rutas.
